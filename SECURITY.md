# Security Policy

## Reporting A Vulnerability

Do not report suspected vulnerabilities through public issues. Use this repository's [private vulnerability reporting](https://github.com/pacharanero/bandmgr/security/advisories/new) instead.

Include the affected commit or version, impact, safe reproduction steps, and any suggested mitigation. Redact credentials and personal data.

## Scope

This policy covers bandmgr. Report upstream dependency vulnerabilities to the affected maintainer and notify this project privately when they affect bandmgr.
